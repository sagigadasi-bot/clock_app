# 🕐 הגיע הזמן

משחק לטלפון שמלמד את רוני לקרוא שעון מחוגים, עם מיצי – גור חתולים חמוד.
HTML + JavaScript רגיל, בלי התקנות ובלי שלב build. עובד גם בלי אינטרנט.

## איך מתקינים על אייפון

1. מפרסמים ב-GitHub Pages (פעם אחת):
   ב-GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   בוחרים את הענף ואת התיקייה `/ (root)`, ושומרים. אחרי דקה-שתיים תופיע כתובת כמו
   `https://sagigadasi-bot.github.io/clock_app/`.
2. פותחים את הכתובת ב-**Safari** באייפון.
3. לוחצים על כפתור השיתוף (⬆️) ← **הוספה למסך הבית**.
4. המשחק נפתח מהאייקון במסך מלא, כמו אפליקציה.

### קול בעברית
המשחק משתמש בקול המובנה של האייפון. לקול הכי טוב:
**הגדרות ← נגישות ← תוכן מוקרא ← קולות ← עברית** ← להוריד את **כרמית (משופר)**.
באזור ההורים אפשר לבחור קול, לשנות מהירות ולבדוק.

## 📲 העברה לטלפון אחר

- **המשחק עצמו:** פותחים את אותה כתובת בטלפון השני ומוסיפים למסך הבית.
- **ההתקדמות של רוני** (כוכבים, מדבקות, שלבים):
  1. בטלפון הישן: ⚙️ (אזור הורים) ← **שליחת ההתקדמות** ← שולחים ב-AirDrop / וואטסאפ / הודעה.
  2. בטלפון החדש: פותחים את המשחק מהאייקון ← ⚙️ ← מדביקים את הקישור ← **קבלת התקדמות**.

  > באייפון, אפליקציה שהוספה למסך הבית שומרת נתונים בנפרד מ-Safari. לכן עדיף להדביק את הקישור
  > בתוך המשחק, ולא רק ללחוץ עליו (לחיצה פותחת אותו ב-Safari).

## פיתוח

```bash
npm start      # שרת מקומי בכתובת http://localhost:8080
npm test       # בדיקות לניסוח השעות בעברית ולשלבים
```

| קובץ | תפקיד |
|------|-------|
| `js/clock.js` | השעון: ציור ב-SVG, אנימציה וגרירת מחוגים |
| `js/timeText.js` | המרת שעה לעברית ("שבע ושלושים" / "שבע וחצי" / "רבע לשמונה") |
| `js/levels.js` | השלבים, יצירת שאלות ותשובות שגויות "הגיוניות" |
| `js/game.js` | סבב משחק: "מה השעה?" ו"תכווני את השעון" |
| `js/main.js` | המסכים: בית, שלבים, פרס, אלבום, משחק חופשי, אזור הורים |
| `js/audio.js` | הקראה בעברית וצלילים |
| `js/progress.js` | שמירת התקדמות והעברה בין טלפונים |
| `sw.js` | עבודה בלי אינטרנט. **בכל עדכון משנים את `VERSION`** |
